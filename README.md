# Affirmations

Мобильное приложение для спокойной ежедневной практики самоосознанности и
поддержки личных целей. Приложение не ставит диагнозов, не обещает лечение и
не заменяет помощь врача, психолога или другого специалиста.

## Возможности

- Онбординг с мультивыбором алкогольной, никотиновой, связанной с порно и
  цифровой целей, затем выбор одной активной цели.
- Ежедневное чтение аффирмаций в течение 10 минут; тексты можно листать,
  поставить на паузу и продолжить позже.
- Отдельный локальный прогресс для каждой выбранной цели; учёт не более одного
  завершения за локальный календарный день.
- Выбор после 30 завершённых дней: продолжить до 365 дней или перейти к другой
  выбранной цели. После 365 дней можно выбрать следующую цель или завершить
  работу с приложением.
- Настройки для подтверждённой смены цели и двойного подтверждения сброса.
- Нет аккаунтов, сетевой синхронизации и уведомлений.

## Запуск

Требуются Flutter и Dart, совместимые с ограничениями в `pubspec.yaml`.

```powershell
flutter pub get
flutter run
```

В VS Code выберите установленное устройство или эмулятор и запустите
`lib/main.dart`.

## Проверки

```powershell
flutter analyze
flutter test
```

Проверки охватывают календарные границы, таймер и восстановление сессии,
идемпотентность завершения, сериализованные записи, ошибки локального хранения,
онбординг, переходы 30/365 дней и подтверждение сброса.

## Данные и безопасность

Состояние и прогресс хранятся локально на устройстве через
`shared_preferences`. В приложение не добавляйте пароли, токены и медицинские
данные. Сброс удаляет только ключ состояния Affirmations; резервная копия или
синхронизация между устройствами не предусмотрена.

Резкая отмена алкоголя при физической зависимости может быть опасна. План
изменений обсудите с врачом. При судорогах, спутанности сознания или тяжёлом
недомогании немедленно обратитесь в местную экстренную службу. Приложение не
предназначено для ведения кризисных или медицинских ситуаций.

## Структура и ограничение файлов

Код разделён по домену, хранению данных, состоянию приложения и пользовательским
экранам. Каждый исходный файл Dart и тест должен оставаться не длиннее 180
строк. Новые зависимости указываются в `pubspec.yaml`; `pubspec.lock` хранит
разрешённые версии.
